# 💳 Credit Card Fraud Detection

## 📌 Overview

This project uses Machine Learning to detect fraudulent credit card transactions while addressing the highly imbalanced nature of fraud detection datasets.

## 🎯 Project Objective

To build a machine learning model that can identify fraudulent transactions and distinguish them from legitimate transactions.

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- SMOTE
- Random Forest
- Jupyter Notebook

## 🔬 Machine Learning Pipeline

1. Problem Statement
2. Dataset Understanding
3. Exploratory Data Analysis
4. Class Imbalance Analysis
5. Data Preprocessing
6. SMOTE for Handling Class Imbalance
7. Model Training
8. Model Evaluation

## 🤖 Model

**Random Forest Classifier**

SMOTE (Synthetic Minority Oversampling Technique) is used to address the imbalance between fraudulent and legitimate transactions.
